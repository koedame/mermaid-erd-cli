# Security Policy

## Supported Versions

Only the latest released version on npm is actively maintained.
Older versions receive no security fixes.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report security issues via GitHub's private vulnerability reporting:

1. Go to <https://github.com/koedame/mermaid-erd-cli/security>
2. Click **"Report a vulnerability"**
3. Fill in the details and submit

We will reply within 7 days to confirm that we received your report.

This project is maintained on a best-effort basis.
We will aim to provide a fix or workaround as soon as reasonably possible,
depending on severity.
